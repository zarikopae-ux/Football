# Football — مشروع أندرويد أولي

هذه نسخة أولية بواجهة عربية داكنة مستوحاة من تطبيقات نتائج كرة القدم. الاسم والتصميم هنا مستقلان وليسا نسخة رسمية من Yalla Shoot.

## ما الموجود الآن؟
- شاشة مباريات مع بطاقات نتائج تجريبية.
- تبويبات المباريات، الدوريات، المواعيد، الملخصات، والمفضلة.
- تصميم عربي داكن مناسب للهاتف.
- تنبيه واضح بأن البيانات الحالية تجريبية.

## فتح المشروع
1. نزّل وثبّت Android Studio على كمبيوتر.
2. فك ضغط الملف `Football.zip`.
3. من Android Studio اختر **Open** وافتح مجلد `Football`.
4. انتظر Gradle Sync، ثم شغّل التطبيق على هاتف موصول USB أو محاكي.
5. لإنشاء APK اختر **Build > Build APK(s)**.

## قبل نشر التطبيق
- النتائج الحقيقية والترتيب تتطلب API رياضيًا ومفتاحًا خاصًا به.
- لا تضع مفتاح API داخل التطبيق المنشور؛ الأفضل استخدام خادم وسيط لحمايته.
- إشعارات الأهداف تحتاج إعداد Firebase Cloud Messaging وخادمًا يراقب أحداث المباريات.
- الملخصات يجب أن تأتي من روابط رسمية أو مرخّصة؛ هذا المشروع لا يتضمن بثًا مقرصنًا.
- المواعيد في النسخة الحالية تجريبية وليست بيانات مباشرة.

## التقنية
Kotlin + Jetpack Compose + Material 3.
